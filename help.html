Aide & Commandes

Mouvement

  • fd(n) : Avancer de n pas
  • bk(n) : Reculer de n pas
  • rt(deg) : Tourner à droite de n degrés
  • lt(deg) : Tourner à gauche de n degrés
  • setxy(x, y) : Placer la tortue aux coordonnées x, y
  • setheading(deg) : Orienter la tortue (0 = haut)
  • home() : Ramener la tortue au centre

Stylo & Apparence

  • pu() : Lever le crayon
  • pd() : Baisser le crayon
  • pencolor(c), pc(c) : Changer la couleur du crayon
  • fillcolor(c) : Changer la couleur de remplissage
  • setwidth(w), ps(n) : Fixer l'épaisseur du crayon
  • fill() : Remplir la forme actuelle
  • cs() : Vide l'écran et réinitialise la tortue
  • clean() : Efface le dessin sans bouger la tortue
  • canvascolor(c) : Changer la couleur de fond
  • ht(), st() : Cacher/Montrer la tortue

Formes

  • circle(r) : Tracer un cercle de rayon r
  • arc(deg, r) : Tracer un arc de cercle
  • rectangle(w, h) : Tracer un rectangle
  • ellipse(w, h) : Tracer une ellipse
  • line(x1, y1, x2, y2) : Tracer une ligne entre deux points
  • write("texte") : Afficher du texte

Math & Divers

  • sin(d), cos(d), tan(d), atan(y, x)
  • sqrt(n), pow(a, b), pi, exp(n), ln(n)
  • integer(n), round(n), ceil(n)
  • random(n), m(n) : Nombre aléatoire entre 0 et n
  • mod(a, b), modulo(a, b), o(a, b) : Reste de la division
  • rgb(r, g, b) : Créer une couleur
  • repeat(n, () => { ... }) : Répéter n fois
  • posx(), posy(), heading()
  • distance(x, y), towards(x, y)

Média

  • playsound(url) : Jouer un son
  • showimage(url, x, y, w, h) : Afficher une image
  • showvideo(url, x, y, w, h) : Afficher une vidéo
