Aide & Commandes

  • fd(n) : Avancer de n
  • bk(n) : Reculer de n
  • rt(deg) : Tourner à droite
  • lt(deg) : Tourner à gauche
  • pu() : Lever le stylo
  • pd() : Baisser le stylo
  • cs() : Effacer l'écran
  • repeat(n, fn) : Répéter n fois
  • setcolor(c) : Couleur (ex: 'red')
  • setwidth(w) : Épaisseur du trait
